# Personal Project Quizz

Đây là một ứng dụng Quizz cá nhân được xây dựng bằng **React**, **TypeScript**, và **Vite**.

## 🚀 Cách chạy dự án chi tiết

Để chạy dự án này trên máy tính của bạn, hãy làm theo các bước sau:

### 1. Yêu cầu hệ thống
- Đảm bảo bạn đã cài đặt [Node.js](https://nodejs.org/) (phiên bản 18+ được khuyến nghị).
- Đã cài đặt Git.

### 2. Cài đặt các thư viện cần thiết (Dependencies)
Mở terminal tại thư mục gốc của dự án (`d:\FE CODE APP Personal\memu-app`) và chạy lệnh sau để tải về các thư viện:
```bash
npm install
```

### 3. Chạy môi trường phát triển (Development Server)
Sau khi cài đặt xong, bạn có thể khởi động dự án ở chế độ phát triển bằng lệnh:
```bash
npm run dev
```

Sau khi chạy lệnh trên, terminal sẽ hiển thị một đường link (thường là `http://localhost:5173`). Hãy giữ phím `Ctrl` và click vào link đó, hoặc copy và dán vào trình duyệt để xem ứng dụng của bạn.

### 4. Build ứng dụng (Tuỳ chọn)
Khi bạn muốn build mã nguồn ra các tệp tĩnh để deploy:
```bash
npm run build
```
Mã nguồn đã được tối ưu hóa sẽ nằm trong thư mục `dist`.

### 5. Xem trước bản Build (Tuỳ chọn)
Để chạy thử bản build xem có lỗi gì không trước khi deploy:
```bash
npm run preview
```
